# 分阶段业务流程图样式

适用于文档第 2 章的 Mermaid 流程图。采用 RiskHot L0/L1 的职责配色，使用者不需要读取原项目。

## 图的组织

- 总体图展示业务主线，详细图按实际业务阶段拆分，每图聚焦一组相邻职责。推荐每图约 6—15 个节点，超过时先考虑拆分，不为节点数量删掉必要分支。
- 每个阶段子节按“流程图 → 处理说明／步骤表 → 规则与边界”组织；图中写短动作，字段、阈值和完整解释放在图下。
- 第 1.3 节列能力划分；第 2.2 节列详图对应表。详图可以与环节一对多或多对一，但须明确映射。
- 图间用“来自图①：已校验上下文”“进入图③：结果交付”等入口出口衔接；不能用跨 Mermaid 代码块的边引用。
- 相同业务对象在各图保持同名；业务步骤、图号和 AI 任务分别编号，移动章节时同步章节引用。
- 分支标明判定结果，分别连接到对应动作。结束、暂停和可恢复待办语义分清；复核后返回位置可写在图下，避免跨图连线拥挤。

## 节点与颜色

| 类名 | 颜色 | 语义 | Mermaid 形状 |
| --- | --- | --- | --- |
| `ai` | 蓝底白字、粗边框 | AI 分析任务 | `A["AI-模块-01：任务名称"]` |
| `system` | 灰色 | 程序处理 | `B["读取已有记录"]` |
| `decision` | 浅黄 | 规则校验与结果分支 | `C{"校验通过？"}` |
| `review` | 橙色 | 待复核、暂停或条件未确认 | `D(["待复核"])` |
| `port` | 青绿 | 入口、出口及正常结束 | `E(["进入下一阶段"])` |
| `downstream` | 紫色 | 不在本模块内的下游职责 | `F["下游处理"]` |

将本图实际用到的定义复制到 Mermaid 代码块尾部，为每个动作节点指定且仅指定一种责任配色：

```text
classDef system fill:#f1f5f9,stroke:#64748b,color:#0f172a,stroke-width:1.5px
classDef ai fill:#2563eb,stroke:#1e3a8a,color:#ffffff,stroke-width:3px
classDef decision fill:#fef3c7,stroke:#d97706,color:#78350f,stroke-width:2px
classDef review fill:#f97316,stroke:#9a3412,color:#431407,stroke-width:2px
classDef port fill:#ccfbf1,stroke:#0d9488,color:#134e4a,stroke-width:2px
classDef downstream fill:#ede9fe,stroke:#7c3aed,color:#4c1d95,stroke-width:2px
class A ai
class B system
class C decision
class D review
class E port
class F downstream
```

颜色之外仍须有文字和形状说明，不仅靠颜色区分业务含义。人工实际办理步骤不冒充程序处理；可明确标注“人工：复核／确认”，与待复核说明一起呈现，必要时增加并说明独立人工责任样式。

## AI 与下游分组

- AI 任务必须在第 6.1 节登记；未经输入材料支持，不机械地为每一步生成 AI 编号。
- 一个 AI 任务内部需要展示多个分析动作时，用 `subgraph` 标注同一任务编号，内部节点统一用 `ai` 类；程序校验放在分组外。
- 同一任务跨图复用沿用编号；跨模块任务用模块代号区分，避免多个 `AI-01` 混淆。
- 正式创建、更新、保存和分发按实际执行方配色。AI 提供建议不意味着它承担写入动作。
- 下游分组标题注明“非本模块”；仅说明接口去向与责任，不把下游推导或评级纳入本模块任务。

## Mermaid 写法与验证

- 默认 `flowchart TD`；关系总览可用 `LR`。用短英文节点 ID 与带引号的中文标签，长标签用 `<br/>` 换行。
- 单图内节点 ID 和分组 ID 唯一；仅连接已定义节点。分组内部节点也参与入口可达性检查。
- 主路径连续，侧分支从相关判断节点就近离开；交付条件未确定时连到橙色待确认节点，不默认通过。
- 模板的 `{{占位符}}` 位于带引号标签内；生成正式文档时替换。关系模型图不得把未经确认的关系基数当作事实。
- 静态检查覆盖：代码围栏、节点与边引用、入口可达性、配色、图间出入口、AI 编号及图表正文一致性。
- 有现成 Mermaid 渲染环境时，实际检查中文显示、标签遮挡、分支走线和缩放后的可读性；无渲染环境时交付 Markdown 并说明未做渲染验收，不默认联网安装工具。
